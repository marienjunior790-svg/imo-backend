# K Suites — démonstration premium FM Agence

Expérience digitale de refonte pour **K Suites** (Pointe-Noire).

```bash
cd ksuites
npm install
npm run dev
```

Ouvrir l'URL Vite (port 5173). Build : `npm run build`.

Depuis la racine du dépôt IMMO-tec : `npm run dev:ksuites`.

## Données

Pas de prix, téléphone, WhatsApp, adresse d'immeuble, avis ni jacuzzi inventés.
WhatsApp : `VITE_WHATSAPP_E164`. API demande : `VITE_INQUIRY_API_URL`.
Photographies : substitutions Unsplash, à remplacer par le shooting officiel.
